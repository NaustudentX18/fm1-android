What you can do

Play the panel

Keys, buttons, and knobs. Press lower on a key for a harder velocity. Drag a knob to turn it. MASTER is the volume.

Hear it

Stereo audio through the phone. The screen stays on while the app is open. USB or Bluetooth MIDI is accepted when Android already sees the device.

Open a firmware

Use Open .fwsc for a community package or M-VAVE’s own FM-1.fwsc. Tick UC25 flash first if the real unit was sold since autumn 2026.

Keep the saves

Patches written by the firmware stay on the phone, one save per package. Switching firmwares does not wipe the other.

Install on a Samsung

  1. Download the APK. Use the button above. Do not tap the browser download bar afterwards. On a Samsung that tap often does nothing.
  2. Open it from My Files. My Files, then Downloads, then tap fm1-emu.apk. Allow install from My Files if asked. The icon is rust-coloured and the name is FM-1.
  3. Allow the install. Settings, Security and privacy, Install unknown apps, then allow it for the app you opened the file from.
  4. Open FM-1. It starts in landscape and plays the bundled template. Open .fwsc when you want a different firmware.

Delete any older fm1-emu.apk in Downloads first. 0.1.0 would not install. 0.1.2 is the one with the icon.

What is in the file

The engine is joakimeriksson/fm1-emu 0.5.1, MIT. It already runs the JieLi AC791N, including the AArch64 JIT. This Android build adds the touch panel, audio, and the firmware picker. It is not a rewrite of the CPU, and it is not an M-VAVE product.

The firmware that plays on first launch is the fm1-base template, MPL-2.0. Other firmwares are their authors’ and are not in the APK.
