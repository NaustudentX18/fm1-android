# FM-1 for Android

Sideload build of the [FM-1 emulator](https://github.com/joakimeriksson/fm1-emu) for arm64 phones, including the Galaxy S25.

The site and the APK live here:

- Page: https://naustudentx18.github.io/fm1-android/
- Download: https://github.com/NaustudentX18/fm1-android/releases/latest/download/fm1-emu.apk

Not a Play Store app. Android 11 or newer, arm64-v8a. First launch plays the bundled fm1-base template. Open any `.fwsc` from the app, including M-VAVE's own package.

The emulator engine is MIT, by Joakim Eriksson. The bundled demo firmware is the fm1-base template, MPL-2.0, by Charles Vestal. This repository is the install page, not the engine source.
